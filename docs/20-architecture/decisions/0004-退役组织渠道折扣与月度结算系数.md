# ADR-0004: 退役组织渠道折扣与月度结算系数

## Context
本决策取代 [ADR-0002](./0002-组织渠道折扣.md)。旧组织渠道倍率进入基础费用，同一请求随后还可能应用个人倍率。Invoice 又可按月度系数调整展示金额，造成原版报表与实际扣费存在差异。退役须保留旧任务结算所需的事实及已交付账单的核账依据。

## Decision
1. 移除旧组织渠道折扣与 Invoice 月度系数的管理接口和编辑入口。新请求所有阶段均停止读取旧组织渠道快照。`legacy` 和 `frozen` 仍使用旧个人倍率，`active` 按实际模型和渠道从用户、组织、系统默认中选取一个消费倍率。
2. Invoice 页面、接口和 CSV 汇总已确认消费。v10 快照继续读取经校验的整数额度，失效快照从源事实重建。退役前已提交任务继续使用自身持久化快照。
3. 保留旧配置、消费日志和旧重算数据。旧重算被重新领取时原样转存至审计列。已实际对外发送的 CSV 按组织、账期和交付版本独立归档。

## Consequences
新消费倍率只应用一次，当前报表和重下载的账单按实际入账金额勾稽。受旧月度系数影响的账期可能与原版交付金额不同，涉及历史价差时由财务逐笔核账。旧渠道配置不自动转换，须继续履行的条款由 Root 在实时计价启用后按模型和渠道配置。账单切换依赖可恢复的原版 CSV 和目标环境对账。

实现见提交 `3281f63bc`。详细合同见[实时模型折扣架构](../用户与组织实时模型折扣架构设计.md)和[组织账单架构](../组织与组织账单架构设计.md#invoice-月度账单)。生产验收见[路线图](../../50-planning/路线图.md#organization-release)。

## Alternatives Considered
- 继续把旧组织渠道倍率叠入基础费用。个人覆盖仍会受旧倍率影响，无法得到用户、组织和系统互斥的消费口径。
- 自动把旧渠道或月度类别条件批量转换成模型和渠道规则。适用范围不同，可能改变条款未覆盖的模型费用。
- 重下载旧账期时继续应用旧月度系数。相同入口将长期暴露两种消费口径，且无法证明重算文件与实际对外交付版本一致。
