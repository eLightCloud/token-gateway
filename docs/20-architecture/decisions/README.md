# 架构决策记录

## 使用规则

ADR 记录长期有效的决策、理由、后果与备选方案。使用[模板](../../templates/adr.md)，在仓库根目录运行 `task docs:new-adr -- title=中文短标题`。文件名使用四位序号和中文短标题，元数据包含 `adr`、`status`、`date`；替代旧决策时建立双向引用。
