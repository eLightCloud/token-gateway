# 工程文档

## 目标

让开发者能够搭建环境、定位实现、按约束变更并验证。

## 放什么

本地搭建、命令索引、编码与评审规则、领域验证及上游同步。

## 不放什么

架构决策进 20；生产部署和排障进 40；一次性开发过程进 80。

## 阅读顺序

1. [本地环境搭建](本地环境搭建.md) → [命令清单](命令清单.md)。
2. [编码规范](编码规范.md) → [AI 编码指南](AI编码指南.md)。
3. 按任务读[组织模块开发与验证指南](组织模块开发与验证指南.md)或[上游同步与冲突解决指南](上游同步与冲突解决指南.md)。

## 命名格式

使用简洁中文主题名；索引使用 `README.md`。

## 内容格式

先说明适用条件和执行目录，再给步骤、可运行命令与预期结果。 正文只设一个一级标题；当前事实文档包含 `status`、`owner`、`last-reviewed`。

## 编写要求

命令以脚本、Taskfile、makefile 和 package.json 为准；数据库和安全验证遵循仓库 AGENTS.md。
