# 命令清单

## 文档命令
```bash
task docs:check
task ai:check
task docs:new-adr -- title=某个架构决策
```

## 后端命令

```bash
./start.sh
go run . --port 3000
go test ./...
go test ./model ./controller ./router
```

`start.sh` 在未设置 `SQL_DSN` 时使用本地 PostgreSQL 默认连接；显式设置 `SQL_DSN=""` 时保留 Go 服务原有的 SQLite 模式，数据库路径由 `SQLITE_PATH` 指定。切换前先核对已有数据所属数据库并备份，不得因空字符串被默认值覆盖而连接到另一套账本。

本地数据库选择回归：`bun test scripts/local-postgres-dsn.test.ts`。

### 文本流断开续读回归

```bash
go test ./relay/helper ./relay/channel/... ./relay ./service ./controller
go build ./...
```

如果改动 `relaykit/` 或其公开 API，还必须独立验证：

```bash
cd relaykit
GOWORK=off go build ./...
```

## 前端命令
默认前端位于 `web/default/`，优先使用 Bun：

```bash
cd web/default
bun install
bun run dev
bun run i18n:sync
bun run typecheck
bun run lint
bun run format:check
bun run build:check
```
