# 运维文档

## 目标

指导配置、发布、观测、排障和回滚。

## 放什么

环境配置、客户接入、运行手册、指标与专项配置。

## 不放什么

本地开发进 30；架构设计进 20；单次事故过程不写成当前操作手册。

## 阅读顺序

1. [环境配置](环境配置.md) → [运维手册](运维手册.md) → [监控告警](监控告警.md)。
2. 客户首次调用读[客户 API 接入指南](客户API接入指南.md)。
3. 按场景读 [Azure Responses 兼容配置](Azure渠道启用Responses兼容配置.md)；[NGINX 媒体转发入口](NGINX媒体转发入口配置.md)仅供识别旧部署。

## 命名格式

使用简洁中文主题名；索引使用 `README.md`。

## 内容格式

配置说明写作用域、默认值和生效方式；手册写前提、操作、验收及停止或回滚条件。 正文只设一个一级标题；当前事实文档包含 `status`、`owner`、`last-reviewed`。

## 编写要求

配置示例用占位符；发布状态以目标环境证据为准。区分历史配置、演示配置与当前默认。
