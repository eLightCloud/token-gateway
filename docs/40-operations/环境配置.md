# 环境配置

## Vantage 专用接入配置

超级管理员入口：**系统设置 → 运维 → Vantage 接入**，页面路径 `/system-settings/operations/vantage`。该页面配置持久化到主库，多个网关实例共享主库时，保存成功后的新接入请求立即生效，无需重启。

| 配置 | 默认与规则 |
| --- | --- |
| 启用 Vantage 接入 | 默认关闭；启用必须已有应用口令和至少一个合法来源 IPv4 |
| 专用应用口令 | 默认未设置；可生成 32 字节随机密钥并复制，手工输入至少 32 字节；保存空值保持现有口令 |
| IPv4 来源白名单 | 默认空；多个完整 IPv4 以换行或逗号分隔，自动去重；不支持 IPv6、CIDR 或域名 |

已保存口令只能验证，不能重新查看；数据库保存 SHA-256 摘要。生成或更换口令后将明文安全保存到 Vantage 后端配置。口令与模型调用 Key 分开使用。

配置读取/保存接口为 `GET/PUT /api/option/vantage_integration`，复用超级管理员认证和审计。通用配置接口不能读取或覆盖该敏感记录；非法输入和保存失败保持已提交配置。禁用返回 503，错误口令返回 401，非白名单来源返回 403。

来源检查仅使用实际 TCP 对端 IPv4，忽略所有转发地址请求头，无需设置可信代理。普通反向代理连接网关时，TCP 对端为代理地址；需要按 Vantage 出口区分来源时，部署入口须保留 TCP 来源，或在受限专用入口执行来源规则。TLS 终止链路和应用端口均应限制访问，Vantage 校验 HTTPS 证书。

专用接入不设限流参数或限流中间件，使用已有外部流量控制。首次发布此功能后须通过页面初始化；旧 `VANTAGE_*` 环境变量不再作为配置来源。其他网关接口的全局代理和流量控制配置继续由原有功能管理。

日常变更步骤见[运维手册](./运维手册.md#vantage-接入配置变更)，业务合同见[接入方案](../80-dev/2026-10-14-睿观系统模型接入方案.md)。
