# 代理客户观测实施方案

产品范围见[代理分销产品设计](../10-product/代理分销与用户专属倍率产品设计.md#代理客户观测)，接口与权限见[代理分销架构设计](../20-architecture/代理分销与用户专属倍率架构设计.md#代理客户观测读路径)。

## 实施顺序

1. 建立两代理、名下多客户、直属用户及停用客户的隔离夹具。覆盖列表、聚合、筛选、审计目标、任务类别和白名单字段。
2. 新增代理观测读模型、控制器和路由注册。复用归属表、日志和任务表、审计动作与客户账单入口，不变更数据写入、结算、清理或身份流程。
3. 新增代理功能目录与路由。复用现有页面框架、表格、空状态、图表库和代理请求能力。侧栏沿用原菜单图标与顺序，继续以客户管理为默认入口。只维护英文和简体中文文案。
4. 执行 Go 与前端类型、构建和目标回归。在真实 SQLite、MySQL、PostgreSQL 和独立 ClickHouse 验证归属、统计、分页和字段投影，记录数据库版本与结果。用代理账号验证入口、筛选、空状态与账单跳转。

## 交付门槛

五个入口可访问，浏览器和接口均只对已启用且完成安全要求的代理开放。请求篡改、无客户、日志保留及停用客户历史有明确结果。旧管理员、普通用户和客户接口仍按原有权限工作。现有工作区改动保留，数据库与会话验证使用隔离夹具。
