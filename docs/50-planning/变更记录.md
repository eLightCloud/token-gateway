# 变更记录

## 2026-08-09

### Root 只读 Token 账单

- 将 Token 对账范围收敛为仅 Root 可见的只读账单工作台，唯一事实源为现有消费和退款日志，不连接上游、不计算上游成本、不创建平行账本。
- 删除上游连接器、自动同步、attempt/capture/run/resolution/snapshot 领域和主链路插桩，Relay、预扣、结算、退款和异步任务不依赖账单模块。
- 新增客户账单、渠道用量、按上游三个视角，服务端汇总/分组/明细分页、Root 只读 API 与流式 CSV；按上游始终保留当前 API 地址、渠道与模型的完整复合主体。
- 页面收敛为方案 2“Audit Worksheet”单页工作台，首屏展示总体指标和分组，点击后才在抽屉加载明细；七种语言文案已同步。

### 文本流客户断开续读

- 将客户侧输出与已建立上游文本流的读取生命周期分离：客户断开后停止写出，但在空闲和绝对上限内继续解析上游终态与 usage。
- 增加独立 `upstream_result/upstream_error` 并持久化到同一条消费日志，保留 `client_gone` 与上游成功/失败两个正交结果。
- 增加文本流唯一结算门，只允许协议成功终态且完整权威 usage 进入原成功结算路径；本地估算、usage 缺失、异常 EOF 或超时不写普通成功消费日志。
- 真实 Claude Messages、OpenAI Responses 断开样本取得非零终态 usage，Claude 缓存读取分项完整落库；请求 max-tokens 越界错误统一返回 HTTP 400。

## 2026-08-08

### 组织 Invoice 模型分类

- 将 Invoice 模型分类收敛为 `TrimSpace + 小写` 后的精确清单优先匹配，并在启动索引构建时拒绝重复归属；补充显式、无歧义的品牌/家族前缀，避免 `gpt-4o`、`glm-5-turbo` 等明确型号误入 fallback。
- 保留 Claude、GPT、Gemini、Minimax、Deepseek、Kimi 的稳定类别键和排序，新增 GLM、Qwen、向量类别；未命中精确清单或明确前缀的模型继续使用稳定的单模型 fallback。
- 所有类别未配置时继续使用 `1.0000`；未写入、迁移或预置任何财务参考系数，既有月度规则结构和 CAS 语义不变。
- Invoice 表格与系数配置共用独立的类别展示模块，七种语言补齐 Alibaba Cloud 供应标识和向量名称。
- 增加分类目录、归一化、未知模型、默认系数、新类别月度规则、API/CSV 一致性和中文展示回归测试；增加本地 SQLite 人工验收数据脚本。
