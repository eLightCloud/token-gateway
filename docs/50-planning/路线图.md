## 当前发布范围

基础组织管理与 Billing 已上线。当前发布工作聚焦：

- MySQL、PostgreSQL、ClickHouse 的迁移、月份聚合和导出一致性。
- 默认系数 `1.0000` 下 Billing 与 Invoice 的同边界对账。
- 抽查 Invoice CSV 的用户名/真实姓名列、支持渠道成功充值订单、订阅排除、账期边界和导出时即时余额，并确认 EPay 与非订单钱包入账按产品合同不纳入充值行。
- 100 个成员关系窗口、24 个月、50 个模型和 1,000,000 条匹配日志规模的性能验证。
- 经业务确认的历史账号分批回填、审计留存和回填后多维对账。
- 在 SQLite、MySQL、PostgreSQL 和现有日志库分支验证 Token 账单汇总、分组、明细与分页。
- 验证 Token 账单 CSV 与同条件页面明细一致，以及非 Root 全部被拒绝。
- 补齐 Token 账单的加载、空数据、错误、筛选、分页回归，并在安全测试数据下完成已认证视觉验收。
- 按 [运维手册](../40-operations/运维手册.md) 完成文本流单实例观测，并轮换曾在对话中明文出现的受控测试密钥。

## 候选演进项

以下事项不属于当前上线范围，也不代表已承诺排期：

- 为组织 disabled 状态增加强制冻结语义。
- 为超出同步请求时长的大账期增加异步导出。
- 在大组织规模验证后评估批量查询、可移植索引或账单快照。
- 增加受审计的归属起点纠错能力；当前接口只允许向前扩展，不能调晚撤销。
- 组织渠道折扣（请求级折扣）：合同设计已被 [ADR-0002：组织渠道折扣](../20-architecture/decisions/0002-组织渠道折扣.md) 取代，实施进度见 [组织折扣实施进度](./组织折扣实施进度.md)；全栈实现与定向回归已完成，待三数据库发布环境验证与已认证视觉验收。
