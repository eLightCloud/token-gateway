## 同笔金额核验

两条消费日志均是钱包资金、组倍率 `1`、模型倍率 `1.475`、输出倍率 `5`。按原路径截断核算：

| 用例 | 复算 | 日志 quota |
| --- | --- | ---: |
| T1 | `(110 + 131 × 5) × 1.475 = 1,128.375` | 1,128 |
| T2 | `(110 + 128 × 5) × 1.475 = 1,106.25` | 1,106 |
| 合计 | `$0.004468` | **2,234** |

A 的钱包余额和 Key 剩余额度均从 `5,000,000` 降至 `4,997,766`，已用额度均为 `2,234`，请求累计为 2。结算后只有上述两条消费日志，退款日志、任务和待结算 journal 数均为 0。结算后重读钱包与日志，余额及记录数一致。[额度规则](../../.agents/rules/billing.md)

修复前，上游视频签名 URL 的 `HEAD` 返回 403，网关对 API Key 请求返回 502，对签发链接返回 404。此问题影响先发 `HEAD` 探测文件的客户端。浏览器此前已经能通过 `GET` 和 Range 播放及下载。修复将受影响的 Seedance 制品 `HEAD` 转成单字节上游 `GET`，从 `Content-Range` 取完整文件长度，并只向客户端返回响应头。回归用例复现了原来的 502 和 404，修复后同时通过 `HEAD`、条件 `HEAD`（304）、完整 `GET` 和 Range。[修复代码](../../controller/seedance_video_head.go) · [回归用例](../../controller/task_generic_test.go)
